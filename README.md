# Анализ базы доноров DonorSearch

Учебный исследовательский проект на основе анонимизированной базы данных донорской платформы **DonorSearch**.  
Цель — изучить структуру и особенности данных о донорах, их активности, географии, вовлечённости  
в бонусную программу и эффективности планирования донаций.

## Задачи исследования

1. Определить регионы с наибольшим количеством зарегистрированных доноров.
2. Изучить динамику общего количества донаций в месяц за 2022 и 2023 годы.
3. Определить наиболее активных доноров (только зарегистрированные и подтверждённые донации).
4. Оценить, как система бонусов влияет на зарегистрированные донации.
5. Исследовать вовлечение новых доноров через социальные сети: по каким каналам приходят доноры и среднее количество донаций по каждому каналу.
6. Сравнить активность однократных доноров со средней активностью повторных.
7. Сравнить данные о планируемых донациях с фактическими, чтобы оценить эффективность планирования.

## Данные

Источник — анонимизированная база донорской платформы **DonorSearch**.  
Основные таблицы в схеме `donorsearch`:

| Таблица | Описание |
|---|---|
| `user_anon_data` | Профили доноров: `id`, `gender`, `region`, `confirmed_donations`, `autho_*` |
| `donation_anon` | Фактические донации: `user_id`, `donation_date`, `donation_type` |
| `donation_plan` | Запланированные донации: `user_id`, `donation_date`, `donation_type` |
| `user_anon_bonus` | Участие в бонусной программе: `user_id`, `user_bonus_count` |

Ключевые поля `user_anon_data`:

| Поле | Описание |
|---|---|
| `id` | Идентификатор донора |
| `gender` | Пол (может быть NULL) |
| `region` | Регион проживания |
| `confirmed_donations` | Количество подтверждённых донаций |
| `autho_vk` / `autho_ok` / `autho_tg` / `autho_yandex` / `autho_google` | Каналы авторизации |
